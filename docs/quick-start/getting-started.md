# Getting started with Reactotron

## Installing Reactotron

Reactotron exists as a desktop application (written in electron) that communicates with your react or react-native app over websockets. It's available for macOS, Linux, and Windows.

First, install the Reactotron desktop application from this fork's [Releases](https://github.com/hurajgor/reactotron/releases) page.

Once installed, add the matching `@hurajgor/*` Reactotron client to your project as a development dependency. Follow one of these quick start guides to get Reactotron up and running in your project:

- [**React Native**](./react-native.md#installing-reactotronapp)
- [**React**](./react-js.md#installing-reactotronapp)

Do not mix this fork's `@hurajgor/*` packages with unscoped upstream Reactotron packages.
